How to make your first 3D printable voxel model

VoxelShaper is a browser-based 3D editor. A voxel is a unit of volume, like a three-dimensional pixel. By adding, removing and painting voxels on a grid, you can build a model one piece at a time without drawing a conventional CAD sketch.

Open VoxelShaper in a new tab

1. Build a small shape

Open the editor and follow the first-run guide if you are new to the controls. Start with a simple shape, such as a small stepped block, before trying a more detailed object. Select Add mode and place voxels next to each other. Keep the pieces connected if the goal is one printable part.

2. Refine the model

Use Delete mode to remove extra voxels and Paint mode to change their appearance. Adjust the brush size for larger edits, then use a smaller brush for details. Rotate the view to check the model from different angles. Use Undo if an edit does not turn out as intended.

Practice project: a stepped block
  1. Build a connected rectangular base.
  2. Add a smaller second layer on top.
  3. Remove one corner voxel and inspect the result from the side.
  4. Paint a few voxels to make the separate levels easy to see.

For printing, color in the editor alone does not guarantee a multicolor output.

3. Save an editable copy

Use Download Local (.json) in the Advanced Export / Local menu to retain an editable project on your device. You can reopen it using Load Local (.json). The Save option for Hub storage requires sign-in. A JSON project is not a printer-ready file.

4. Export for 3D printing

Open Export Options under Advanced Export / Local. In the wide-screen layout, the mesh export button is 3MF (Bambu Studio); in the narrow-screen layout, it is STL. A G-Code option is also present and requires the integrated slicer to initialize successfully. STL is a mesh format, while 3MF can carry additional model information. Check the scale; the Up-Axis setting applies to STL.

5. Check the model before printing

For STL or 3MF, open the exported file in a compatible slicer and inspect the physical dimensions, orientation, connected geometry, wall thickness and layer preview. Voxel geometry can still contain unsupported overhangs or disconnected pieces. Use settings appropriate for your printer, material and nozzle. G-Code is printer-specific; do not send it to a printer without verifying its compatibility and settings.

Where do AI-generated voxel models fit?

VoxelShaper Hub provides a separate entry point for managing models and links to the MCP tools for AI agents. If you are interested in generating voxel models with an AI agent, use the existing VoxelShaper MCP documentation on the Hub. This guide focuses on manually editing and preparing a model in the browser.
